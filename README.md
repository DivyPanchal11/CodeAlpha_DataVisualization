# CodeAlpha Data Visualization Task

## Objective
Create visual representations of book pricing data.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Visualizations Created

1. Histogram
2. Box Plot
3. Bar Chart
4. Pie Chart

## Insights

- Most books are priced between £20 and £50.
- A few books have significantly higher prices.
- Price distribution is relatively balanced.
- Visualizations help understand trends quickly.

- histogram.png
- boxplot.png
- top10_books.png
